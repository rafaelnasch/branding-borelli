Antes de colar

Cinco regras antes de qualquer código.

Valem para os dezesseis blocos. O resto está no comentário que abre cada código.

A marca é arquivo

Sempre um arquivo de assets/ ou o data URI deste código. Nunca redesenhe, redigite BORELLI em fonte, recolora, gire, estique, contorne ou aplique sombra ou brilho. E nunca cole o SVG do logotipo dentro do HTML: use <img>.

A versão segue o fundo

Ouro metálico sobre Azul Noite ou Abismo. Azul Borelli sobre Papel, Névoa ou branco. Branca sobre o Azul Borelli, foto escura com sombra de leitura e vídeo. O ouro nunca vai para o claro.

Respiro de x

Nunca digite um data URIEstes códigos têm até 106 mil caracteres. Copie pelo botão, que leva o código inteiro. Nunca resuma, reconstrua ou escreva um data URI de memória. E nunca cole o SVG do logotipo dentro do HTML: os identificadores internos do desenho colidem com os da página.
